# Ecodash App

Aplicação front-end de monitoramento de eficiência e sustentabilidade.

## Visão geral

Projeto em Vite + React + TypeScript com Tailwind CSS, Radix UI e TanStack Router.

## Como usar

```bash
npm install
npm run dev
```

Abra http://localhost:5173 no navegador.

## Scripts úteis

- `npm run dev` — iniciar o servidor de desenvolvimento
- `npm run build` — gerar a versão de produção
- `npm run preview` — ver a build localmente
- `npm run lint` — executar o ESLint
- `npm run format` — formatar o código com Prettier

## Estrutura principal

- `src/` — código fonte
- `src/components/` — componentes UI e páginas
- `src/routes/` — definição de rotas
- `src/hooks/` — hooks personalizados
- `src/lib/` — utilitários e helpers
